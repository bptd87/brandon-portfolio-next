# Original Project Detail Page Design Analysis

## Key Design Elements from brandonptdavis.com

### Layout & Structure
- **Hero section**: Large blurred background image with title overlay
  - Title in large italic serif font
  - Venue and location below title
  - Year displayed
  - Like count and view count icons
  
### Content Sections
1. **Project Overview** (heading)
   - **Design Notes** (bold, inline)
   - Long-form design narrative
   - "...Read More" button to expand

2. **GALLERY (12)** - Collapsible section
   - Grid of production photos
   
3. **RENDERINGS (1)** - Separate collapsible section
   - Grid of rendering/sketch images

4. **CREATIVE TEAM** - Collapsible section
   - Two-column grid
   - Role name on left, person name on right
   - Roles: Playwright, Director, Scenic Design, Costume Design, Lighting Design, Sound Design

### Visual Style
- **Minimalist and clean**
- Dark background with light text
- NO glass effects or cards on main content
- Simple typography hierarchy
- Generous white space
- Collapsible sections with subtle borders

### Key Differences from Current Implementation
- NO "About This Project" section (description is for SEO only, not displayed)
- Design Notes are the MAIN content, not a secondary section
- Galleries are collapsible, not always expanded
- Renderings are separate from production photos
- Creative team is in a simple two-column layout, not a card
- Overall much more minimalist - no glassmorphism, no heavy cards

### Typography
- Large italic serif for project title
- Clean sans-serif for body text
- Uppercase labels for sections (GALLERY, RENDERINGS, CREATIVE TEAM)
