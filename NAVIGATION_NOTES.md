# Navigation Structure from Original Site

## Header Navigation
- Logo: "B BRANDON PT DAVIS SCENIC DESIGNER" (left)
- Main Nav Items (center):
  - PORTFOLIO (dropdown with 4 disciplines)
  - NEWS
  - ABOUT
  - ARTICLES
  - STUDIO
- Right Side:
  - Search icon
  - Theme toggle
  - CONTACT button (outlined)

## Portfolio Dropdown Structure
When clicking PORTFOLIO, shows 4 discipline options:
1. **Scenic Design →**
2. **Experiential Design →**
3. **Renderings →**
4. **Scenic Models →**

## Portfolio Page Layout
- Hero section with discipline title (e.g., "Scenic Design")
- Subtitle: "Spatial Storytelling & Environments"
- Filter tabs for subcategories:
  - ALL
  - COMEDY
  - DRAMA
  - MUSICAL THEATRE
  - SHAKESPEARE
  - THEATRE FOR YOUNG AUDIENCES
- Grid of project cards with:
  - Large image
  - Category badge (top left)
  - Project title
  - Theatre/Client name
  - Year
  - Tags

## Key Design Elements
- Clean, minimal navigation
- Dropdown shows all 4 disciplines at once
- Each discipline is a separate filtered view of projects
- Subcategories provide additional filtering within discipline
- All projects use /portfolio?filter=discipline URL pattern (but we'll use /projects/:slug for detail pages)
